The LED

For test 2, slow-motion filming: green (0, 255, 0) at 20%, the same every session. The board starts with this setting.

Moving a control lights the LED for 2 s so you can see it. Between messages it is dark, so every message starts with a clean dark-to-lit edge.

The LED cannot change during a transmission: it is the instrument being measured.
